# 图片批量填字工具 v1.0

在图片底板（如荣誉证书、奖状、邀请函、工牌、标签）上，按**像素精确定位**批量填入 Excel 表格数据，批量生成图片并导出 PDF。纯前端实现，所有处理都在本机浏览器完成，不上传任何数据。

## 使用方式

直接用浏览器打开 `index.html` 即可使用，**完全离线**（单文件版，约 2.2 MB）。也可以把本仓库部署到任意静态托管（如 GitHub Pages）在线使用。

## 功能

- **四步流程**：① 导入表格 → ② 上传底图 → ③ 定文字位置 → ④ 批量导出
- **Excel 导入与数据检查**：支持 .xlsx/.xls/.csv，第一行为表头、一行生成一张图；导入后自动检测空白单元格（整行空白、已绑定字段列的空白等）并标出
- **像素级定位**：每个文字字段可输入原始像素坐标与字号（与百分比实时同步），方向键 1 像素微调（Shift 为 10 像素）；画布带缩放、网格/中心线、标尺、鼠标实时坐标读数与十字线
- **字体**：系统默认与本地字体，可导入 .ttf/.otf/.woff/.woff2 字体文件直接使用（适合硬笔书法等字体）；字间距、行间距均可调，所有调整在预览图上实时呈现真实效果
- **总预览**：全部成品缩略图一屏总览；点击图片空白处切换效果预览
- **图片水印**：在文字字段之后添加水印图，同样支持像素定位与缩放，可指定页码（全部 / 指定页码 / 奇数页 / 偶数页）
- **导出**：
  - PDF（共享底图流式导出）：底图原文件在 PDF 中只存一份、不重新编码（零画质损失），水印只存一份，每页只增加文字层小裁剪；千页级文件可控制在几十 MB，且生成过程流式写盘/写文件，不因文件大而失败；带导出进度与剩余时间倒计时
  - 图片 ZIP / 单张图片：原图清晰导出，单张上限 3 MB
  - 导出支持按行分批与中途取消

## 性能

按上万条数据量级优化：底图只缓存一份、导出复用画布、总预览分批生成、数据表分页渲染、时间片让行避免页面卡死。

## 技术说明

单文件 HTML + Canvas 绘制；Excel 解析（SheetJS）、ZIP 打包（JSZip）、PDF 兜底路径（jsPDF / pdf-lib）均为开源组件，已内嵌于 `index.html`，无需联网加载。
